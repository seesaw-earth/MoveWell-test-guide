# MoveWell 测试动作指导 · Test guide demo

MoveWell 各项老年人运动功能测试的 3D 动作示范：一个不露脸的小人在房间里做出每项测试。

- **动作**：步骤随小人的动作逐条亮起，计时或计数同步显示。
- **摆放**：需要准备什么、先确认哪些安全条件、手机放哪里（视野和距离），以及“看看手机拍到什么”。
- **要点**：正确做法和常见错误并排或叠加对照，附计分规则和安全提示。

共 12 项：计时起立行走（TUG）、边走边说动物名的 TUG、5 次起坐、30 秒起坐、4 米步行、站立平衡、原地转身、震颤录像，以及老年人体适能测试（Senior Fitness Test）的 30 秒屈臂、2 分钟原地踏步、椅式坐位体前伸、背后够手。中文、English、Español；浅色和深色。

A 3D demonstration of each of MoveWell's movement tests for older adults: Movement, Setup (with what the phone sees) and Key points (the right way beside a common mistake). Twelve tests, in Chinese, English and Spanish.

## 打开 · Open

一个文件，不联网：直接用浏览器打开 `index.html`，或访问 GitHub Pages 上的网页。
One file, no network: open `index.html` in a browser.

示范动作是示意图，不是医疗建议；测试方法以 MoveWell App 和所引用的指南（CDC STEADI、SPPB、WS/T 887—2026、Senior Fitness Test 等）为准。
The movements are illustrations, not medical advice.
